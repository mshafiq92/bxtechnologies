# BX Technologies logo set (web)

> **Master set, not published.** This folder is the designer's complete logo package and guide
> (`BX-Logo-Guide.pdf`). The website publishes only the files it uses: `public/brand/`
> (horizontal compact colour and white SVG, compact PNG for share images, 512px icon) and the
> browser icons in `app/` (`icon.svg`, `icon1.png`, `apple-icon.png`). Stacked, print and no-bars
> versions stay here.

All text is converted to outlines. No fonts are needed. Gradient IDs are unique per file.

horizontal/
- bx-logo-horizontal-compact (C1) (.svg/.png) . website header, light backgrounds (recommended, 40-60px tall)
- bx-logo-horizontal-compact-white . website footer, navy #0B1F33 (40-48px tall)
- bx-logo-horizontal-compact-nobars / -nobars-white (C2) . same as C1 without the bars. Below 40px tall, mobile, email signatures, app screens
- bx-logo-horizontal / -white . larger uses, 60px and up

stacked/ . business cards, title slides, social, merchandise. Not on the website.
print/ . bx-logo-original / -white with "Pvt Ltd". Letterheads, invoices, contracts.
icon/ . bx-mark, bx-favicon.svg, bx-favicon-32/-180 (white bg)/-512.png
guide/ . BX-Logo-Guide.pdf (save from the export dialog into this folder).
CLAUDE-CODE-PROMPT.md . instructions for updating the website.

Website: use ONE layout everywhere (horizontal-compact in header, horizontal-compact-white in footer).
Legal name "BX Technologies Pvt Ltd" goes in the footer copyright line as text.

Wordmark outlines are set in Source Sans 3 Regular (open licence), the closest available match to Myriad Pro.
